# Texas Chronic Disease Risk Factor Analysis

## Project Overview
This project analyzes chronic disease risk factors across Texas counties using public health and socioeconomic data.

## Core Question
Which demographic, behavioral, and socioeconomic factors are associated with chronic disease prevalence in Texas counties?

## Planned Data Sources
- CDC PLACES
- U.S. Census ACS
- Texas Health Data Portal

## Skills Demonstrated
- R data cleaning
- Exploratory data analysis
- Statistical modeling
- Geospatial visualization
- Public health analytics
